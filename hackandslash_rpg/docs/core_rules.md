# Core Rules

Rules basis: **D&D Rules Cyclopedia (RC)**.

## Combat Mechanics

Current rules for combat mechanics development:

* **Armor Class:** Uses ascending Armor Class.
* **Attack:** `d20 + attack bonus >= AC`.
* **Damage:** Weapon damage roll + applicable modifiers.
* **Initiative:** Uses a d6 with individual initiative.
* **Hit Points:** Fighters use a d8 Hit Die. Monster Hit Dice always use d8s, following the RC standard.
* **Defeat:** A combatant reaching 0 HP is defeated.

### Future Development

* **Character Hit Dice:** Determine character Hit Dice from character class once the class system is integrated.
