# New Map Persistence Architecture
┌─────────────────────────┐               ┌──────────────────────────────┐
│     PYTHON BACKEND      │               │      BROWSER FRONTEND        │
│                         │               │                              │
│  FastAPI / Flask Server │  JSON / WS    │  HTML5 Canvas / Phaser.js    │
│  - Generates Maps       │ ────────────> │  - Loads tile assets         │
│  - Handles Chat Engine  │ <───────────  │  - Renders isometric math    │
│  - Saves to Database    │               │  - Displays side chat UI     │
└────────────┬────────────┘               └──────────────────────────────┘
             │
             ▼
┌─────────────────────────┐
│     DATABASE / DISK     │
│  JSON / SQLite          │
│  - Stores grid array    │
│  - Stores chat history  │
└─────────────────────────┘

## DB Options
Prototyping use Json File
Growing to scale use SQLite (or something similar)

## Real-time Chat Events
1. Client laods page (HTTP request to Python: GET /api/map)
2. Python reads the Json or SQLite and sends the array to the map
3. Javascript receives the Json array and draws the images on html using the isometric coordinate math from pygame_map
4. WebSocket connection to allow typed chat messages or modifies a tile, the server immediately broadcasts that change to all connected browsers
